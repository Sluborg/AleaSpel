# B10: UI icons (9 images)

No template image. Every image:

One friendly app icon for a children's game: a simple symbol with thick rounded shapes, soft
shading, bright pastel colours (see `STYLE.md`, but bolder and simpler than the objects). It must
read clearly when shown very small (128 pixels). Centred, filling about 80% of the canvas. All
nine in the same style so they look like one icon set.

nothing green on the icon.
