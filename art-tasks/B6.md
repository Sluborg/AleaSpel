# B6: clothes (6 images)

Template for every image: https://raw.githubusercontent.com/Sluborg/AleaSpel/main/assets/source/base/master-raw.png

Keep EVERYTHING identical to the template: the same girl, face, hair, skin, grey unitard, pose,
size, position on the canvas, framing, lighting and the flat green background. Do not move,
resize, redraw or restyle the character.

Only change per image: add the one item. The item is solid bright pink (#FF4FA3) with no pattern
(the game recolours it). It fits the body like real clothing. The grey unitard stays visible where
the item does not cover it.

Canvas exactly 1024x1536 pixels. Flat green background #00FF00, no shadow, no glow, no text.

1. `tshirt_basic`: a short-sleeved loose T-shirt.
2. `shorts_gym`: short gymnastics shorts.
3. `dress_basic`: a simple knee-length dress with short sleeves.
4. `jacket_track`: a zip-up track jacket with long sleeves (zip in the same pink).
5. `slippers_gym`: gymnastics slippers (soft ballet-style shoes).
6. `socks_ankle`: ankle socks.
