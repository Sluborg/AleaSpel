# Visuals night loop (plan and review routine)

Visuals runs in rounds (about every 30 minutes) without Stefan. Goal: the game feels smooth,
pretty, cute, fun and easy for a 9-year-old. Every round follows this routine.

## Each round

1. **Sync:** `git fetch` + rebase on `main`. Read new entries in `docs/art-discussion.md` and new
   rows in `docs/art-requests.md`. Answer Lead there.
2. **Inbox:** check `art-inbox/STATUS.md` and the Drive folder. Check and ship finished batches
   (`scripts/art/inbox.mjs`, visual review, `scripts/art/ship.mjs`), write redos to
   `art-tasks/REDO.md`.
3. **Work:** take the top open item from the backlog below. One item per round, small enough to
   finish, test and push in the round.
4. **Test:** lint, format, typecheck, `validate:art`, build, then a phone-size browser run
   (Playwright, Pixel 7) of every screen the change touches, with screenshots looked at.
5. **Review before push:** re-read the diff as a reviewer, with the child in mind:
   - Can a 9-year-old understand it without reading? Big targets (>= MIN_TOUCH), clear
     feedback, nothing that looks broken or cut off.
   - Cute and consistent with `art-tasks/STYLE.md`; no clipping, no halos, no jumpy motion.
   - Smooth: no long waits, no stutter; loading only what is needed.
   - Nothing of Lead's broken (scenes still open, their fallbacks still work).
6. **Push** to `main` (one topic per commit), then mark the item done here with one line.
7. **Wake others only when needed:** ChatGPT via the art-wake pull request when new batches are
   queued; Lead via `docs/art-discussion.md` (and a direct session nudge if Lead's work is blocked
   on something of mine).
8. **Log** one line per round in the "Round log" below. No message to Stefan unless something
   needs his decision; he reads this log in the morning.

## Safety rules

- Never change the save format without a migration; never break existing saves.
- Never touch Lead's files; ask in the discussion.
- If a change fails its tests twice, revert it and log why instead of pushing half-work.
- Stop making new art batches if more than 3 batches are waiting for review.
